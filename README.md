# Photoname

Rename your photos using the date each one was taken, such as `2026-11-07_001.jpg`.

## Features

- Rename all photos in a folder by the date each photo was taken.
- Number photos taken on the same day in order.

## Prerequisites

- Python 3.10 or later
- Linux, Windows, or macOS

## Installation

```bash
pip install photoname
```

## Quick start

Rename the photos in a folder:

```bash
photoname /path/to/photos
```

Expected output: Each photo is renamed to match the date it was taken, for example `2026-11-07_001.jpg`.

## Usage

Run the command with the path to the folder that contains your photos:

```bash
photoname /path/to/photos
```

Replace `/path/to/photos` with your folder path.
